# V3.1 预算功能微调需求文档

## 一、背景

当前「同行旅」小程序的预算功能已经具备基础能力，但在真机调试和实际交互中发现以下问题：

1. 未设置预算时，账单页底部仍然展示与预算相关的信息，存在冗余。
2. 已设置预算后，预算栏和账单统计区域存在信息重复。
3. 创建者添加、修改或删除预算后，加入者端不会及时刷新，只有在点击「添加账单」等操作后才更新，刷新时机不合理。
4. 之前已经提出过的预算功能要求需要继续保留，不允许回退或只改前端。

本次需求是对预算功能做一次小范围但完整的体验和逻辑修正。

## 三、已有要求必须继续保留

以下是之前已经确认过的预算功能要求，本次修改必须兼容：

### 1. 预算卡片位置规则

* 未设置预算时，预算设置入口应该放到账单页最下方。
* 已设置预算后，预算卡片保留在当前靠上的位置，方便查看预算使用情况。
* 合理性：如果用户不想设置预算，不应该长期在页面顶部看到预算入口。

### 2. 删除预算冗余展示内容

设置预算后，预算区域中不再展示以下冗余内容：

* 人均已花费
* 旅行入账
* 不参与花费统计等额外说明

这些功能如果是之前新增出来的，不要只删除前端展示，也要删除对应的新逻辑、计算字段或无用状态，避免留下死代码。

### 3. 预算输入校验

设置预算时，输入金额必须使用和记账金额相同的校验逻辑：

* 必须是正数。
* 最多两位小数。
* 不能为空。
* 不能输入非法字符。
* 不允许 0 或负数。
* 错误提示应清晰。

### 4. 当前总花费计算

预算中展示的当前总花费必须和账单页「总消费」的计算逻辑保持一致。

尤其要注意：

* 入账/退款类账单不应该错误增加总花费。
* 如果现有账单页总消费计算结果是正确的，应优先复用该计算结果或抽取统一计算方法。
* 不允许预算区域单独写一套不一致的总花费计算逻辑。

### 5. 预算状态显示

* 设置预算后，账单页不能继续显示「暂未设置预算」。
* 清除预算后，必须真正清除云端/本地状态。
* 清除后再次进入账单页，应恢复为未设置预算状态。

## 四、本次新增需求

## 阶段一：优化未设置预算时的展示

### 目标

未设置预算时，页面应该更简洁，避免普通加入者看到不必要的预算入口或预算信息。

### 需求 1：未设置预算时隐藏当前总花费

当前未设置预算时，下方不需要展示「当前总花费」或类似预算相关统计。

要求：

* 如果没有设置预算，不展示当前总花费。
* 不展示预算进度。
* 不展示预算相关的支出统计。
* 页面只保留正常账单列表和正常账单统计信息。

注意：

* 这里隐藏的是预算相关区域里的「当前总花费」。
* 账单页原本用于账单汇总的统计信息是否展示，要结合阶段二统一调整。

### 需求 2：未设置预算时，加入者不显示底部预算条

当前未设置预算时，预算设置入口应该只对旅行创建者显示。

要求：

* 如果当前用户是旅行创建者，未设置预算时，可以在账单页底部看到「设置预算」入口。
* 如果当前用户是普通加入者，未设置预算时，不显示最下方预算条。
* 普通加入者不应该看到「暂未设置预算」「设置预算」之类的操作入口。
* 普通加入者进入账单页时，预算功能应该表现为不存在，而不是显示一个不可操作入口。

权限规则：

* 旅行创建者：可以设置、修改、删除预算。
* 普通加入者：只能在预算已设置后查看预算使用情况，不能设置、修改或删除预算。
* 未设置预算时，普通加入者不需要看到任何预算相关 UI。

### 阶段一验收标准

完成后请停止，并让我检查：

* 创建者未设置预算时：预算入口在账单页底部。
* 加入者未设置预算时：完全看不到预算条。
* 未设置预算时：不显示预算区域里的当前总花费。
* 不影响正常账单列表展示。
* 不影响添加账单功能。

## 阶段二：解决已设置预算后的重复统计问题

### 当前问题

已设置预算后，预算栏会显示「当前已花费」。

但账单页下方或其他统计区域又显示：

* 总消费 xxx
* x 笔

这会导致「已花费」和「总消费」语义重复，页面信息密度过高。

### 设计方案

采用以下方案：

## 已设置预算后，将账单统计区域改为“账单概览”，避免重复展示总消费金额

### 具体规则

当预算已设置时：

1. 预算栏负责展示金额类核心信息：

   * 总预算
   * 当前已花费
   * 剩余预算
   * 使用进度

2. 原来的账单统计区域不再重复展示「总消费 xxx」。

3. 原来的账单统计区域可以改为轻量级「账单概览」，只展示非重复信息，例如：

   * 账单笔数：x 笔
   * 最近一笔账单时间
   * 是否存在待结算账单，若当前已有相关逻辑

4. 如果代码中暂时没有「最近一笔账单时间」或「待结算」的成熟逻辑，不要为了这个需求强行新增复杂逻辑。
   最低要求是：

   * 已设置预算时，下方不再显示「总消费 xxx」。
   * 可以只保留「共 x 笔账单」。

### 推荐展示文案

已设置预算时，账单统计区域建议显示：

```text
账单概览
共 x 笔账单
```

如果容易实现最近账单时间，可以显示：

```text
账单概览
共 x 笔账单 · 最近更新：MM月DD日 HH:mm
```

如果实现最近更新时间需要大幅改动，则不要做。

### 未设置预算时的展示规则

未设置预算时，账单页可以继续保留原来的账单统计：

```text
总消费 xxx
共 x 笔
```

原因：

* 未设置预算时，没有预算栏承载「当前已花费」。
* 这时展示总消费是合理的。

### 阶段二验收标准

完成后请停止，并让我检查：

* 未设置预算时：账单页可以显示「总消费 xxx，共 x 笔」。
* 已设置预算时：预算栏显示「当前已花费」。
* 已设置预算时：下方不再重复显示「总消费 xxx」。
* 已设置预算时：下方最多显示「账单概览 / 共 x 笔账单」等非重复信息。
* 当前已花费金额必须和账单总消费逻辑一致。
* 入账/退款类账单不能错误计入花费。

## 阶段三：修复加入者端预算刷新时机

### 当前问题

真机调试中发现：

* 创建者添加预算后，加入者端不会及时看到变化。
* 创建者删除预算后，加入者端也不会及时更新。
* 加入者端通常要点击「添加账单」或触发其他操作后才刷新。

这说明预算数据刷新时机不合理。

### 目标

预算数据应该在用户进入账单页或切换到底部菜单「账单」时刷新。

### 需求

当用户点击底部菜单进入「账单」页时，应主动刷新以下数据：

1. 当前旅行信息。
2. 当前预算设置。
3. 当前账单列表。
4. 当前账单统计结果。

尤其是预算相关数据：

* budgetAmount
* budgetEnabled / hasBudget
* budgetUpdatedAt
* totalExpense / currentSpent
* 其他现有代码中用于预算显示的字段

### 实现建议

优先使用页面生命周期和 Tab 切换触发逻辑：

* 如果账单页是 tabBar 页面，优先检查 `onShow` 是否每次都会触发。
* 在 `onShow` 中调用刷新账单页数据的方法。
* 如果已有 `loadBills`、`loadTripDetail`、`loadBudget`、`refreshData` 等方法，应复用或整合。
* 不要只在 `onLoad` 中加载预算，因为 `onLoad` 不会在每次切换 tab 时触发。
* 不要依赖点击「添加账单」来间接刷新预算状态。

### 数据一致性要求

创建者执行以下操作后：

* 添加预算
* 修改预算
* 删除预算

加入者端在点击底部「账单」菜单重新进入账单页时，应看到最新状态。

要求：

* 不强制做实时 WebSocket 或订阅推送。
* 本阶段只要求在进入账单页时刷新即可。
* 刷新过程应避免明显闪烁。
* 刷新失败时应保留合理错误提示或静默失败策略，不要导致页面崩溃。

### 阶段三验收标准

完成后请停止，并让我检查：

* 创建者设置预算后，加入者点击底部「账单」页能看到预算栏。
* 创建者删除预算后，加入者点击底部「账单」页后预算栏消失。
* 不需要点击「添加账单」才刷新。
* 添加/删除账单后，预算当前已花费也能正确更新。
* 不影响账单列表加载。
* 不影响普通成员权限。

## 五、最终测试场景

请在全部阶段完成后，协助我检查以下场景：

### 场景 1：创建者未设置预算

预期：

* 预算设置入口显示在账单页底部。
* 不显示预算当前总花费。
* 正常显示账单列表。
* 可以设置预算。

### 场景 2：加入者未设置预算

预期：

* 看不到预算设置入口。
* 看不到暂未设置预算。
* 看不到预算当前总花费。
* 可以正常查看账单列表。
* 不能设置预算。

### 场景 3：创建者设置预算后

预期：

* 预算栏显示在账单页靠上位置。
* 显示总预算、当前已花费、剩余预算、进度。
* 下方不重复显示「总消费 xxx」。
* 可以修改或删除预算。

### 场景 4：加入者查看已设置预算

预期：

* 可以看到预算栏。
* 不能修改或删除预算。
* 当前已花费和创建者端一致。
* 不显示重复总消费统计。

### 场景 5：预算刷新

预期：

* 创建者添加预算后，加入者点击底部「账单」菜单即可刷新看到。
* 创建者删除预算后，加入者点击底部「账单」菜单即可看到预算消失。
* 不需要点击「添加账单」才刷新。

### 场景 6：退款/入账账单

预期：

* 退款/入账不应该错误增加当前已花费。
* 预算栏当前已花费和账单总消费逻辑一致。
* 删除或编辑退款账单后，预算统计同步变化。
